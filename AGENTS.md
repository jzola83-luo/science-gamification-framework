# Guidance for educational game design

When designing or reviewing an educational game in this workspace, read [EDUCATIONAL_3D_GAME_DESIGN_PRINCIPLES.md](EDUCATIONAL_3D_GAME_DESIGN_PRINCIPLES.md), use its P1-P10 principles as the default research-informed review frame, and check that the game provides the seven core learning-game functions listed there.

For design decisions, identify the relevant principle IDs and explain the concrete learner-facing choice. Keep source findings separate from design interpretations. The evidence base includes a small exploratory 2006 classroom study and a 2018 book synthesizing broader frameworks and practices; do not present either as definitive or universal. If adding evidence or changing guidance, update the guide's research record with source, context, and limitations.
